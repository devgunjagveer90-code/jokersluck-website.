# Jokersluck Agency Website

This repository contains the source code for the Jokersluck agency landing page.

## Features
- Modern, responsive design.
- Portfolio section showcasing previous work.
- Functional contact form with backend integration.

## Tech Stack
- **Frontend**: HTML5, CSS3
- **Backend**: Python Flask
- **Database**: SQLite (synced via team-db)

## Setup
1. Create a virtual environment: `python3 -m venv venv`
2. Install dependencies: `./venv/bin/pip install flask`
3. Run the application: `./venv/bin/python app.py`

The website will be available at `http://localhost:8000`.

## Assets
- **Branding**: Official logos and brand kits are located in `assets/`.
- **Portfolio**: Client samples are organized by project in `assets/portfolio/`.
- **Marketing**: Promotional flyers are located in `assets/marketing/`.
